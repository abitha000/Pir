# Authentication checklist

- [ ] Configure Supabase Auth providers.
- [ ] Configure site URL and redirect URLs.
- [ ] Enable email verification if required by deployment.
- [ ] Configure password-reset redirect URL.
- [ ] Add organization onboarding flow.
- [ ] Add server-side role checks for privileged operations.
- [ ] Test RLS with two organizations and two users.
- [ ] Never ship a service-role key to the browser.
- [ ] Add audit logging for membership and role changes.
- [ ] Add session revocation/account disable workflow for administrators.
